## Test design

- 3 known-stance questions (topics on which the person has repeatedly stated a public position) + 1 out-of-scope question (a topic the person hasn't taken a clear position on, testing honest inference) + 1 style-sample question
- The answering agent only reads this skill's own directory files, with internet access disabled; the scoring agent runs independently, judging against PG's real public positions
- Basis: the SkillLens paper (arXiv 2605.23899) found LLM self-evaluation accuracy is only 46.4%, so answering and scoring are strictly separated
